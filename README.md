# AW2 Overhaul

A gameplay overhaul mod for [Commander Wars](https://github.com/Robosturm/Commander_Wars):
persistent unit experience, new units (drones, MANPADS, engineers), new maps
and a short campaign. Work in progress.

## Installation

1. Clone this repository into the `mods` folder of your Commander Wars
   installation, under the name `aw2_overhaul`:
   ```
   git clone https://github.com/LeoMD-ctrl/AW2-overhaul.git "<Commander Wars>/mods/aw2_overhaul"
   ```
2. Start the game, open the options, enable **AW2 Overhaul** in the mod list
   and restart the game.

See `CLAUDE.md` for the project vision, conventions and modding notes.
