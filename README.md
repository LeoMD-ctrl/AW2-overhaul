# AW2 Overhaul

A fan project: an Advance Wars-style tactics game with persistent
progression, new modern units (drones, MANPADS, engineers with field
camps), new maps and a short story campaign.

The design lives in `docs/design.md`. The engine is not chosen yet; see
`docs/engines/candidates.md`. A first prototype as a Commander Wars mod is
on hold (`docs/engines/commander-wars.md`).
