# Pipeline sprites sans dessin

1. Génération (PixelLab, Retro Diffusion) ou rendu 3D (Blender + Mixamo).
2. Nettoyage automatique : palette imposée, transparence nette, calage des images.
3. Assemblage dans Aseprite (animations nommées).
4. Validation par l'outil du jeu.

Détails : `docs/art-workflow.md` du dépôt AW2 Overhaul.
