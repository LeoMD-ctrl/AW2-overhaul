# Évaluer un moteur avant de s'engager

1. Jouer au jeu 1 heure : finition, interface, sensations.
2. Lire la documentation officielle de modding.
3. Lire 2 mods publiés (le code réel, pas les descriptions).
4. Lister les besoins du projet et marquer chacun : vérifié / à tester / impossible.
5. Faire 2 ou 3 petits tests (« spikes ») sur les points à risque avant tout gros travail.
